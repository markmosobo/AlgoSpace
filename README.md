## Getting Started

To get a local copy up and running follow these simple example steps.

## Requirements

The current package requirements are:

- **Frontend:** Vue.js 3 (or 2)  
- **Other Dependencies:** Axios, Vue Router, Vuex/Pinia (if applicable) 

### Installation

_Below is an example of how you can instruct your audience on installing and setting up your app. This template doesn't rely on any external dependencies or services._

1. Get a free API Key at [https://github.com](https://github.com)
2. Clone the repo
   ```sh
   git clone https://github.com/markmosobo/AlgoSpace.git
   ```
3. Install NPM packages
   ```sh
   npm install
   ```  
4. Finally, open two seperate terminals/cmd and at the project level run these two commands 
   ```sh
   npm run dev
   ```
